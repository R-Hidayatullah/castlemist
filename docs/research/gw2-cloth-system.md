GW2 cloth physics lives in `Arena\Engine\Gr\GrCloth.cpp` (distinct from the MODL cloudData/lightData effects in [[gw2-particle-system]]). It is a classic Verlet / Position-Based-Dynamics solver, fixed 30 Hz step.

**Key funcs (imagebase 0x140000000):**
- `sub_140A8FE50` = GrCloth::Simulate — force accum (gravity 384 + wind + character-motion inertia), Verlet integrate free verts, then `m_numIterations` (a1+532) relax passes; drives locked verts from skeleton first. dt=1/30 (0.033333335), dt²=0.0011111113. drag = 0.99999899 − windResistance·0.7.
- `sub_140A90F30` / `sub_140A91210` = distance-constraint solvers (clamped vs max-stretch). Edge packed as 4×u16 = [idxA, idxB, flags, restLenHalf]; restLen is a **half-float** decoded inline. flags bit0 clear → asymmetric split by weld blend, set → 50/50. Stiffness picks stretch vs compress by (dist>restLen). Both end with a **weld pass** copying pos vert→vert (GR_CLOTH_CONSTRAINT_RELATIONSHIP_WELD).
- `sub_140A922A0` = sphere obstacle (type 0), `sub_140A91950` = capsule (type 1, swept-sphere/segment, asserts GR_OBSTACLE_TYPE_CAPSULE). Obstacles ride skeleton bones (world = bone·local per frame).
- `sub_140A92A50` = GrCloth::Finalize — frame-fraction lerp between physics frames + skin to output vertex buffer; rebuilds normals/tangents/bitangents (sub_140A98DD0/97CB0).
- `sub_140A97CB0` = normal/tangent/bitangent rebuild: per output vert, blends adjacent per-face tangent frames. m_vertGroups (a1+896, 16B stride [count,ptr]) holds baked adjacency; facelist = 8B [faceIdx u32, weight f32]; faceFrames buffer = 48B/face (3×vec4 = N/T/B rows). Weighted-sum + affine apply. Per-face frames computed by sub_140A97450 during Simulate.

**File format:** ModelClothData in MODL packfile, versions V19–V33 (obstacles added V29). Chunks: ModelClothConstraint, ModelClothBoneWeight, ModelClothMeshGroup, ModelClothData, ModelClothObstacle, ModelClothSoftLock, ModelClothGroupBinding. First `m_numLockedVerts` (a1+672) verts are skeleton-driven Dirichlet anchors. On-disk layout driven by ArenaNet pf reflection typeinfo (32-byte field records `[name,subtype,size,typecode]` @0x141ee9500../0x141f08130..; type-code enum NOT yet decoded — read field NAMES/ORDER from there, sizes from the header row size field 0xDE=222 etc).

**Byte-exact layouts (confirmed from disasm):**
- `ModelClothConstraint` = **8 B**, proven by loader `sub_140A95430` (reads file from base+6 backwards): `@0 distance`(half rest-len), `@2 relationship`(0=asym,1=sym,2=WELD), `@4 vertIndexA`, `@6 vertIndexB`. Welds = relationship==2 run at tail (assert `!weldsHit`). Rest positions come from mesh geoData, NOT the cloth chunk.
- `ModelClothObstacle` = **50 B** (sub_140CE1FF0): `@0 affinity`, `@4 bone`(u64 token), `@12 type`(u8 sphere0/capsule1), `@13 response`, `@14 flags`, `@26` 16B transform, `@42 length`, `@46 width`(radius=width/2).
- `ModelClothData` sim params (float block @4..@31 + @0xD0..) proven from setter call site 0x140ce27b4 → sub_140A97120 (clamps+stores): `@4 rigidness`→+512 windResistance[0,1], `@8 gravityCoef`→+516 gravityScale[-2,2], `@0xC`→+524 stretchStiffness(1-x)[0,1], `@0x10`→+536 weldBlend[0,1], `@0x14`→+528 compressStiffness(1-x)[0.3,1], `@0x18`→+520 inertiaMass[1,10], `@0x1C dragCoef`→+544 windCoef[-2,2], `@0xD0 flags`(bit6→maxDistSolver +576, bit7), `@0xD1 iterations`(u8)→+532[1,8], `@0xD2`→+540[0,1]. Constructor sub_140A8E510 seeds defaults (iter=1, windCoef=0.5, others 1.0/0.0). solveEdges stiffness proven at call site 0x140a90849 (xmm1/2/3 ← obj+0x20C/0x210/0x218 = +524/+528/+536): a2=stretch(+524, used when dist>restLen), a3=compress(+528), a4=weldBlend(+536, asym split). Inertia params (sub_140A8FE50 @0x140a903a0): accum += dir·(-speed)/+520·(1.0-+540) into +234/238/23C; +520=inertiaMass[1,10] (@0x18), +540=motionFollow[0,1] (@0xD2); higher mass/follow → cloth rigidly follows body. (flt const=1.0f @0x14191FBDC). `loadClothParams()` in ModelClothData.cpp fills full ClothParams (windResistance/gravityScale/windCoef/iterations/maxDistSolver + stretch/compress/weld stiffness) with exact clamps + the 1-x inversion (validated).
- `ModelClothData` = **222 B** (0xDE): `@0 geoData`, `@32 fvf`, `@60 vertexCount`, `@64` boneWeightGroups ptr (12B group `{u32 count; ptr@+4}` → 9B entries `{u64 bone; u8 w/255}`), `@84/88` softLockCount/ptr (3B `{u8 w; u16 idx}`), `@96/100` constraints0(LOD0), `@108/112` constraints1(LOD1), `@156/160` obstacleIndexCount/ptr, `@208 flags2`, `@214 rootBone`. Chunk root: `@20/24` obstacleCount/arr, `@48/52` clothCount/arr(222 stride).
- Reader `minieditor/ModelClothData.h/.cpp`: opaque-blob + offset-exact accessors (never guesses padding) → ClothLoadResult (edges/welds/boneWeights/obstacles) for GrCloth. Validated: half-decode, weld split, locked-count, capsule radius all correct.
