**Bind-pose joint position** = translation of inverse(InverseWorld): R=IW top-left 3×3, t=(IW12,IW13,IW14), worldPos = −t·R⁻¹ (t as row vector). This is the exact model→bone bind matrix used to skin the mesh, so its inverse translation lands in mesh space with no hierarchy accumulation — the robust way to draw the rig aligned to geometry. Fallback = compose local translations down parents.

**GPU MESH SKINNING — DONE + verified (2026-07).** The mesh now deforms with the animation (not just the skeleton overlay). Chain: vertex FVF carries **BlendWeights (bit 0x2, 4×u8 norm) + BlendIndices (bit 0x4, 4×u8)**; the index points into the mesh's **`boneBindings` (ModelMeshDataV66 field, token64[])**; each token → a skeleton bone.

**Bone-name→token64 REVERSED from the engine (IDA `sub_140E3B5E0`, ModelBones.cpp path via `sub_140CE7C10`→`sub_140CF7420` binary-search over a sorted {token,idx} table).** It is NOT a hash — it's a pack: strip a leading `"bone:"`, then **5 bits per letter** (a-z/A-Z→1..26, LSB-first, ≤12 chars/60 bits); if the name **ends in two decimal digits**, that number goes in the **top nibble** (bits 60-63) (engine does `v6=lastByte+10*secByte; token|=v6<<60`, so nibble = number mod 16 — non-letters pack as 0). `castlemist::model::tokenizeBoneName()` implements it; `Extractor::resolveBoneBindings` builds token→bone-index per skeleton and maps each mesh's `boneBindingSkelIndex[]`. **Verified 53/53 (+9/9/7/7/34/34) bindings resolve on springer 562804.** (Weapons like 471720 resolve 0 — they use an EXTERNAL rig, `ModelFileSkeleton.fileReference`; external-skeleton loading is still TODO.)

**Skinning math (verified `skel` CLI `skinIdentityRms`):** per bone `SkinMat_row = InverseWorld_row · AnimatedWorld_row`; `AnimatedWorld_row` = row-major of compute_world's (lin,pos) i.e. linear=lin^T, translation row=pos. At bind/zeropose `SkinMat≈I` (rms 5e-6) so rest mesh is undistorted; a posed bone deforms correctly. `model_renderer.cpp`: `GVertex` +`bidx[4]`(u32)+`bwt[4]`(stride 88), input layout +BLENDINDICES(R32G32B32A32_UINT@56)+BLENDWEIGHT(@72); **bone palette cbuffer `register(b1)` `float4x4 gBones[256]`** (DYNAMIC, `update_bone_palette` each frame — identity when clip=-1); HLSL VS does LBS `sm=Σ bwt·gBones[bidx]`, transforms pos+tangent-frame. `uHasSkin` in CB (per-submesh `SubMesh.hasSkin && g_skin_ok`, g_skin_ok = inline rig ≤kMaxBones).
