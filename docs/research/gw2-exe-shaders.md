**The Gw2-64 client .exe embeds ~2275 bgfx shader blobs in `.rdata`, far beyond the 58 material shaders.** Found 2026-07-11 in `Gw2-64-disable-aslr.exe.i64` (imagebase 0x140000000) via magic scan for `56 53 48 0B`(VSH v11)=1214, `46 53 48 0B`(FSH v11)=1050, `43 53 48 0B`(CSH v11)=11. This is the answer to "the exe also has camera/lighting shaders" — it does, and they're the class MISSING from the AMAT-only reconstruction (see [[gw2-shaders-dxbc]]).

**Layout of the shader `.rdata`:**
- `0x141932030 – ~0x141AB7BD0`: the **58 built-in MATERIAL AMAT packages** (`MATERIAL_SHADERS_BUILT_IN`), indexed by shaderId 0-57 in the switch table **`sub_1402F46E0`** (each case: `*a2=&blobPtr; *a3=byteSize; *a4=techniqueCount`; case 58 = MATERIAL_SHADER_CUSTOM asserts "must be loaded from a file"). These contain per-material VS/FS variants (uniforms incl. `CameraPosition` strings at 0x14193xxx). Already extractable via the AMAT path.
- `~0x141AF6FD4 – 0x1420399xx`: the large **ENGINE GRAPHICS shader set** — standalone raw bgfx VSH/FSH blobs (NOT AMAT-wrapped, NO code xrefs; reached via base-ptr+directory at load). Uniforms confirm they're engine shaders: `ViewProjection`, `World`, `TexTransform0A/0B`. Includes minimal **camera-only** VS (e.g. 0x141BE6A04 = 1 uniform `ViewProjection` Mat4@reg0 + 644-byte DXBC) = depth/shadow/z-prepass shaders that DON'T exist in material AMATs. String pools (Amat/Bgfx assert strings @0x141D0xxxx) are interleaved in this span.
- `0x14203ABE0 – 0x142054xxx`: **11 COMPUTE shaders**, each a full ArenaNet packfile `PF\x04 … COMP GRCS` ("ComputeShaderBinary", chunk fourcc `COMPGRCS`, GR Compute Shader). Byte pattern `50 46 04 00 00 00 0C 00 43 4F 4D 50` finds exactly 11.

**How shaders are ordered/identified (runtime):**
- Asset level: `shaderId`. Material 0-57 → `sub_1402F46E0`; shaderId ≥ 58 loaded from dat AMAT `BGFX` chunk via **`sub_140AA6DC0(shaderId, 0x58464742 'BGFX', 3, &count)`** (BgfxShader.cpp, `sub_140BF94A0` builds the shader obj → passes via `sub_140BFBFD0`).
- GPU level: per-context lazy **`graphicsShaderCache[shaderId]`** array (`BgfxDraw.cpp:146`, filler `sub_140AB04A0`, slot ptr `sub_140255150`).
- Blob→GPU: **`sub_140B5AD60` IS bgfx `ShaderD3D11::create`** (renderer_d3d11.cpp). Parses magic+ver (v83 first byte 'V'/'F'/'C'), uniform count u16, per-uniform {nameLen u8, name, type u8, num u8, regIndex u16, regCount u16, texInfo u16@v≥8, texFmt u16@v≥10}, codeSize u32, DXBC code, attrs. Computes a **content hash** of the DXBC (`sub_140C17920`/`sub_140C18D60`, stored a1+164) = the shader's identity; then D3D11 `CreateVertex/Pixel/ComputeShader` at device-vtable +96/+120/+144. Error strings: "Failed to create {fragment,vertex,compute} shader. Hash %u." Ordering within a program = uniforms in blob order; cbuffer filled by `regIndex` as BYTE offset (matches [[gw2-shaders-dxbc]]).
- Lighting-specific: `GR_SHADER_MIN/MAX_POINT_AND_SPOT_VS_CONSTANTS` (BgfxDdi.cpp, `sub_140B00F40`, value 16..64 pow2) = point/spot light VS constant slots.

**EXTRACTOR + DIRECTORY BUILT (2026-07-11):** `gw2mcp/tools/extract_exe_shaders.py` (portable, parses the PE directly — no IDA) scans `.rdata`+`.data` for the 3 magics and walks each self-delimiting bgfx blob (`ShaderD3D11::create` layout: magic4, hashIn, hashOut@v≥6, count u16, per-uniform{nameLen,name,type,num,regIdx u16,regCnt u16,texInfo@v≥8,texFmt@v≥10}, codeSize u32, code, numAttrs u8, attrs u16*, constBufSize u16). Validates VS/PS code begins `DXBC`. Output `gw2mcp/tools/exe_shaders/`: `cso/NNNN_<T>_<hash>.cso` (raw DXBC, D3DReflect-verified to load; cbuffers=0 b/c bgfx strips RDEF), `manifest.json` (per-blob type/version/hashes/region/role/uniforms), `stage_candidates.json`, `README.md`. **2244 validated blobs**: material 1115 / engine 1094 / compute 35 (V 1209, F 1024, C 11). Engine blobs carry NO ArenaNet names (release-stripped) — the "directory" is CONTENT-derived: pick a shader by its **uniform signature** (authoritative) + DXBC hash.

**Engine-shader directory by pipeline stage** (concrete cso indices in stage_candidates.json): DEPTH/SHADOW VS (27, uniforms={ViewProjection} only, e.g. #1140); **FORWARD SH-lit PS** (20: shRed/shGreen/shBlue + shSun/shSunColor/shSunData + WorldToShadowD + shadow sampler gSs15, e.g. #1428/#1437) = the AUTHENTIC replacement for castlemist's hand-written `kLightHLSL`; SKY/atmosphere PS (16: FogColorFar,skypara,sunDir,sunClr, e.g. #1611); **LightBuffer deferred-sample PS** (87: LightBuffer,ScreenDims,StippleDensity + light sampler gSs12, e.g. #1274); POST fullscreen PS (ModelColor,fxclr, e.g. #1135); **COMPUTE auto-exposure/tonemap** (11: ExposureControl #2215/#2218, Exposures #2217, HistParams #2221/#2222 = luminance histogram, FusionExponents #2223 = exposure fusion). These match the sh*/LightBuffer/StencilId/fxclr/stipple uniforms already reverse-engineered in [[gw2-shaders-dxbc]].
